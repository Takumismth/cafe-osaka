
# Osaka Coffee

Сайт кофейни **Osaka Coffee** — современный лендинг с меню, корзиной и оформлением заказа.

## Возможности

- Меню по категориям: Кофе, Авторские, Холодные, Выпечка, Каталог
- Карточки товаров с описанием и модальным окном
- Корзина с группировкой одинаковых позиций (×2, ×3…)
- Оформление заказа и чек
- Светлая / тёмная тема
- Адаптив под мобильные
- Мягкие звуки при кликах
